## Core Themes

- **Scope amplification** — Staff engineers are evaluated on impact beyond their immediate team
- **Ambiguity tolerance** — most real problems arrive without clear requirements; Staff engineers create structure
- **Trade-off articulation** — saying "it depends" with a clear framework is a strength, not a dodge
- **Communication as a skill** — how you present a design matters as much as the design itself
