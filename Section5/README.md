## Interview Simulation Format

Every chapter has a `## Interview Simulation` section following the 5-phase framework at Senior SWE level:

```
Phase 1: Requirements      (8 min)
Phase 2: Estimation        (4 min)
Phase 3: API Design        (4 min)
Phase 4: Data Model        (4 min)
Phase 5: HLD + Deep Dive  (20 min)
Common Cross-Questions
```

---

## L5 vs L6 Bar

**L5 answers** demonstrate correct patterns, reasonable trade-offs, and clean estimation.

**L6 answers** (Section 6) additionally cover org complexity, migration paths, multi-region design, build-vs-buy decisions, and operational safety.

Where a chapter has a paired Staff version, read the L5 chapter first — it gives you the foundation, and the L6 version shows what "one level up" looks like.
