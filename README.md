# System Design for L6: The Complete Guide

A 128-chapter system design course targeting Google L5 (Senior SWE) and L6 (Staff Engineer) interviews.

Every chapter follows a consistent format: intern→staff progression, real-world incidents, ASCII diagrams, exercises, and homework. All 59 case study chapters (Sections 5–6) include a full interview simulation with cross-questioning.

## What This Course Covers

- System design patterns and trade-offs
- Distributed systems theory (consistency, replication, consensus, CAP/PACELC)
- Google's internal systems (GFS, Bigtable, Spanner, Borg, Chubby, MapReduce)
- 59 fully worked case studies with Staff-level interview simulations
- Engineering craft (debugging, migrations, observability, code review)
- Behavioral interview preparation and offer negotiation

**Not covered:** Coding/DSA rounds — prepare those separately.
